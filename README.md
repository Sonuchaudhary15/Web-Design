1. Freshcart Landing Page Clone

This project is a responsive front-end clone of the Freshcart grocery landing page, created as part of a website cloning assignment.
The main goal of this project was to practice building a real-world landing page layout and making it responsive across different screen sizes.

The website is built using only HTML, CSS, and Bootstrap 5. No backend, JavaScript frameworks, or build tools were used.

2. Live Preview

To view the project, simply open the index.html file in any modern web browser.
You can also use a local static server such as the Live Server extension in VS Code for a better development experience.

3. Technologies Used

a. HTML5 – for structuring the page content

b. Bootstrap 5.3 (CDN) – for responsive layout, grid system, and UI   components

c. Custom CSS (styles.css) – for additional styling and small design adjustments

4. Project Structure & Features

index.html – a single-page landing layout that includes:

A sticky navigation bar with logo, search bar, and cart options

A hero section highlighting the main promotional message

“Shop by Categories” section with category cards

“Best Selling Products” section displaying product cards

A promotional banner with an email subscription form

Footer with useful links, app download buttons, and social media icons

styles.css – custom styles added on top of Bootstrap to improve the overall look and feel

5. How to Run the Project Locally

Download or clone the repository.

Open the project folder.

Choose one of the following options:

Option A: Double-click index.html to open it in your browser

Option B: Use a static server such as VS Code’s Live Server extension

The layout is fully responsive and works well on mobile, tablet, and desktop screens.
